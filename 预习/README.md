# 预习（01、02 与测试脚本）

这个目录是**学习区**，专门放"看懂了但还没进正式流水线"的代码。正式流程在 `../src/`。
两个目的：① 按课件顺序复习；② 做实验/试错，坏了也不影响主流程。

## 1. 这里有什么

| 文件 | 是什么 | 对应课件 |
|---|---|---|
| `01_EDA分析.py` | 脚本版 EDA：读数据 → 看结构 → 标签分布 → 文本长度 → 数据质量 → 数据集泄漏 → 画两张图 | `01_data/01_EDA分析.py` |
| `02_EDA函数封装.py` | 函数版 EDA：把 01 拆成函数，额外输出 `eda_summary.json` | `01_data/02_EDA函数封装.py` |
| `90_Flask入门测试.py` | Flask 最小 demo（两个路由），验证环境 | `02_rf/src/flask_api.py` |
| `91_API接口测试.py` | 向 8001 接口发一条 POST，验证联调 | `02_rf/src/predict_test.py` |
| `课件参考_TMF_Code/` | 整套课件原始代码副本 | 全量 |

### `课件参考_TMF_Code/` 结构

```
课件参考_TMF_Code/
├── 01_data/       01_EDA分析.py  02_EDA函数封装.py  03_数据处理.py
│                  data/（原始数据副本）  eda/（JSON 报告 + 4 张图）
└── 02_rf/         src/（app/config/flask_api/predict/predict_api/predict_fun/predict_test/train/index.html）
                   data/（CSV + 停用词）  model/（两个 pkl）
```

> 这是**只读参考**。课件里 `01_data/` 的脚本用的是 `./data/...`、`../data/...` 相对路径，必须在对应目录下运行；我们自己的 `01/02` 已经改成基于 `PROJECT_ROOT` 的绝对路径，随便哪个目录运行都能找到文件。
> 复制时排除了 `__pycache__` 和 `.idea`（IDE 配置，引用的是旧路径）。

## 4. 后续预习怎么做（推荐路线）

1. **先跑通 01 → 02**，对照 `课件参考_TMF_Code/01_data/` 里的同名文件，逐段 diff：我们这边多了什么、少了什么（主要是路径和注释）。
2. **新建** `03_xxx.py` 之类的实验文件，不要改 `01/02`，这样复习时原件永远可对照。
3. 学完一课就在本文件第 3 节的表里打勾或补一行笔记，避免下次接不上。
4. 想把实验提升为正式代码，就复制到 `../src/` 并按步骤编号命名（`08_xxx.py`）。
